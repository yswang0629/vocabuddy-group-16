## project introduction

VocaBuddy 是一個簡單的英文單字學習網站，適合透過單字卡、隨機測驗與單字庫練習高中英文單字。網站不需安裝額外套件，直接以瀏覽器開啟即可使用。

## new vocabulay & functions

VocaBuddy 提供初級、中級與中高級三個級數的單字練習。

#### Functions

- 單字卡：顯示隨機單字，點擊可查看中文、詞性與級數；可瀏覽上一張與下一張。
- 測驗：可選擇級數與 1 至 50 題的題數；題目會從所選級數隨機抽出。
- 測驗選項：每題皆為中文選項，並依題目的主要詞性分組。
- 測驗結果：答題後立即顯示對錯，1 秒後自動進入下一題；結束後顯示時間、正確率與錯題回顧。
- 單字庫：依級數篩選，並按英文字典序列出英文、中文與詞性。

## program execution mode

1. 下載或複製此專案。
2. 以瀏覽器開啟 `index.html`。
3. 從上方選擇「單字卡」、「測驗」或「單字庫」開始使用。
